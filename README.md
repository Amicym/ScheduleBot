# 🎓 College Schedule Telegram Bot

Асинхронный Telegram-бот на **Python** и **aiogram 3**, предназначенный для быстрого и удобного просмотра расписания занятий в колледже. Бот забирает актуальные данные с официального сайта и выводит их в структурированном виде.

---

## ✨ Основные возможности

* 📅 **Просмотр расписания:** Получение актуального расписания пар на сегодня и любой другой день.
* 🔄 **Удобная навигация:** Быстрое переключение дней с помощью Inline-кнопок (◀️ Вчера / Завтра ▶️).
* 👥 **Выбор курса и группы:** Удобное меню выбора с возможностью сменить группу в любой момент.
* 📚 **Поддержка подгрупп:** Четкое разделение пар по подгруппам без путаницы.
* 🚀 **Высокая скорость:** Асинхронный парсинг и обработка запросов.

---

## 🛠 Технологический стек

* **Язык:** Python 3.10+
* **Фреймворк:** [aiogram 3.x](https://github.com/aiogram/aiogram)
* **Запросы / Парсинг:** `aiohttp` / `BeautifulSoup4`
* **Окружение:** `python-dotenv`
